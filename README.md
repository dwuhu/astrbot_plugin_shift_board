# 排班工坊 · 工时与工薪

**`astrbot_plugin_shift_board`** · 给 AstrBot 的排班 / 考勤 / 工时 / 工薪插件

作者：[DwuHu（九月月）](https://github.com/DwuHu) · 仓库：[github.com/DwuHu/astrbot_plugin_shift_board](https://github.com/DwuHu/astrbot_plugin_shift_board) · 当前版本：**v1.13.5** · 近期更新日志：[CHANGELOG.md](CHANGELOG.md)

> 月休 4 / 6 / 8 天自动排班，上下班打卡算工时，同一天重叠打卡按时间区间自动去重，时薪或月薪自动核算；AI 一句话就能排班、补一段日期的打卡、设置工资。首次打卡之前的日期自动显示「未上班」，也可手动标记未上班 / 请假，这些天不计薪、月薪按实际在职工作日折算。工资按月独立存档，10 月 3000、11 月 5000 互不覆盖，实习期和正式期也按月份分开记；`/打卡 状态` 直接告诉你现在几点、今天已经上了多久，年收入只按真正打卡上班的天数累计，不拿未来班表预测。新增加「发薪中心」：按月看应发、已到账、未发，支持「当月月底发」和「压一月 · 次月指定日期发」切换，发薪日到点主动提醒「工资到账没有」；给 AI 说「今日考勤」会单独弹一张图，今天上了多久、今天按时薪实时赚了多少、距下班还剩多久、本月「应得 / 实得 / 未发」三个小窗口都在上面，实得按出勤天数一天一天涨，今日收入按小时一小时一小时叠加。今日考勤图和整月排班图的右上角会显示天气图标、温度和天气现象，但不显示城市；图上还会按早上 / 中午 / 下午 / 晚上给一句问候，中午问「吃饭了吗」，下午说「还有多久下班、晚上去哪玩」。排班图里今天这一格是黄色，边框有一圈按「今天已上 / 今日班次总时长」实时走的进度灯带，已完成的白天是绿色、还没上班的是蓝色，排班图与帮助图默认约 1080P、最高不超过 1.5K，字体也换成更清晰的 Noto Sans SC。上下班提醒支持自定义文案，设置城市后由 AI 联网搜索天气写进提醒，只带天气现象、温度和「天冷了记得加衣」，不再显示城市名。每月房租、社保、水电、伙食等固定扣款标签完全自定义，后台用环形图看占比；超过每日标准工时还会单独推加班提醒，休息日提醒只在前一天上班、后一天排休时出现。`/排班 帮助` 会生成图文手册，22 个 AI 工具覆盖排班、工时、工薪、发薪到账、今日考勤图、整月排班图、年收入、扣款、提醒和打卡。附带液态玻璃风格的 WebUI 排班日历、工时看板、按月工资档案、发薪中心与费用构成图。

班表按人独立生成，打卡自动算实际工时，正常工资、加班费、缺勤扣款、罚款一起结算；
WebUI 支持日历补录、整库 JSON 备份和打卡 CSV 批量导入，暗色 / 亮色都适配。

## 功能一览

| 模块 | 能做什么 |
| --- | --- |
| 排班 | 按月休 4/6/8 天生成整月班表；月休 4 天按周日单休、月休 6 天按三个双休周末、月休 8 天按双休；也可关闭「周末优先」按均匀间隔排休 |
| 打卡 | `/打卡 上班`、`/打卡 下班` 实时计时；`/打卡 状态` 显示现在几点、今天累计上了多久、离下班还剩多久；`/打卡 补 11-20 09:00 18:00` 补录；`/打卡 删 11-20` 清空当天；也可以让 AI 一次补一段日期的历史打卡 |
| 工时 | 今日 / 本周 / 本月 / 本月明细，统计实际工时、计划工时、加班工时、出勤天数、缺勤天数、完成率；进行中的打卡会实时累计「今天已上多久」，并倒计时「距下班还剩多久」 |
| 工薪 | 时薪制或月薪制；月薪自动折算时薪，输出正常工资 + 加班费 − 缺勤扣款 − 罚款 − 每月固定扣款、到手工资、全月预测、日薪；首次打卡前、未上班 / 请假都不计薪，月薪按实际在职工作日折算 |
| 工资档案 | 每个月的工资单独存：10 月 3000、11 月 3400 / 5000 互不覆盖；每个月可标「实习 / 正式」，转正后不会把历史月份改成正式工资 |
| 发薪中心 | 按月算应发 / 已到账 / 未发；发薪规则可切「当月月底发」或「压一月 · 次月 N 号发」；登记部分到账、补齐全额、撤销到账；WebUI 与排班日历直接标「发薪 ¥金额 / 未发」；发薪日到点主动提醒「工资到账没有」 |
| 今日考勤图 | `/今日考勤` 单独发一张 760px 视口、1.8× 超清输出（约 1.5K，封顶不再放大）的卡片：右上角显示天气图标、温度和天气现象，但**不显示城市**；下面按早上 / 中午 / 下午 / 晚上给一句问候（吃饭了吗、还有多久下班、晚上去哪玩）；今天上了多久、按小时实时累计的「今天已获得」、距下班还剩多久；本月三个小窗口「应得 / 实得 / 未发」，其中实得按已出勤天数一天一天累计，本月没上满不会提前显示整月工资；上月按整月固定；另列所有未发合计、下次发薪日、发薪规则与本月还要上多久 |
| 排班图 | `/排班 图` 与 AI「排班图」走 840px 视口 + 1.3× 输出（约 1080P，最高不超 1.5K）：今天这一格用**黄色**高亮，边框是一圈按「今天已上 / 今日班次总时长」实时走的进度灯带（像电池一样往前充，满了就是一天），格子里同时写「上班中 20%」；已完成是绿色、未上班/排班中是蓝色；右上角同样显示天气图标和温度，不显示城市，并带时段问候 |
| 年收入 | 只按已经打卡上班的天数累计，未来班表不提前算钱；月薪制出勤一天加一天日薪，时薪制按实际工时加钱，实习 / 正式分开统计，同时给应发和到手 |
| 固定扣款 | 房租、社保、水电、伙食、通勤、话费……标签完全自定义；可选「每月」长期扣或「仅本月」一次性扣；同一标签重复添加会更新金额而不是叠加重复行 |
| 加班 | 每日标准工时默认 8 小时，超过部分自动算加班；加班倍率可改；到点单独推「加班提醒」，员工可自己开关 |
| 提醒 | 工作日自动推温柔版「早安 / 快收工啦」，提前分钟数可配；上班/下班文案可按人自定义占位符；设置城市后 AI 联网搜索天气并写进提醒，只写天气现象、温度和穿衣建议，不再把城市名带进聊天；温度偏低时自动补「天冷了，记得多加件衣服」；已打卡的不重复催，下班打卡顺手结算今天入账；休息日提醒独立开关，只在前一天上班、后一天排休时提醒，周六周日排班写着上班也不会误报 |
| AI 工具 | 22 个 Function Calling 工具：查班表/今日/工时/工资/发薪/年收入/设置/扣款，单独发今日考勤图和整月排班图，口头写排班、月薪/时薪（可指定月份）、工资阶段、发薪规则、到账登记、标准工时与加班倍率、提醒文案、天气城市、罚款、每月扣款、批量补卡、删除打卡 |
| 帮助 | `/排班 帮助` 优先用 t2i 生成液态玻璃图文手册（900px 视口 + 1.3×，约 1080P），字体换成 Noto Sans SC 并加深卡片底色、提亮正文，和背景形成对比；t2i 不可用时自动回退文字版 |
| 隔离 | 每个「平台 + 账号」一条独立记录，排班/打卡/工资/扣款/提醒全部按 `user_key` 分区，换群不串数据 |
| WebUI | `排班日历`：点任意日期可补录、删除打卡，或标记未上班 / 请假 / 恢复工作日，发薪日直接标出「发薪 ¥金额 / 未发」；`发薪中心`：未发合计、下一笔、规则切换、次月几号、发薪日提醒开关与时间、每月应发 / 已到账 / 未发明细、登记与撤销到账；`费用构成`：环形占比图 + 可编辑扣款清单 + 添加表单；`工时看板`：到手工资、实时「现在几点 · 今天已上多久 · 距下班还剩多久」、完成率环、近 14 天工时柱状图；`工资档案 · 年收入`：今年实际收入、实习 / 正式分栏、按月工资档案；提醒区有独立「休息日提醒」开关；顶部可切员工、切月休方案、翻月；右侧可导出/导入整库备份、导入打卡 CSV |

## 安装

### 方式一：插件市场（上架后）

AstrBot WebUI → 插件 → 插件市场 → 搜索「排班工坊」或 `astrbot_plugin_shift_board` → 安装 → 启用。

### 方式二：手动安装

1. 把整个 `astrbot_plugin_shift_board` 目录放进：

   ```text
   <AstrBot 根目录>/data/plugins/astrbot_plugin_shift_board
   ```

2. 打开 AstrBot WebUI → 插件管理 → 找到「排班工坊 · 工时与工薪」→ 启用 / 重载插件。
3. 在 QQ 里发送 `/排班 帮助` 查看全部指令。
4. WebUI 里点插件卡片，进入「排班日历 · 工时看板」页面即可打开看板（右侧还有提醒设置）。

> 依赖：只用 AstrBot 自带的 `aiosqlite`，无需额外 pip 安装。

### 装好后先做这三步

```text
/工薪 时薪 18          # 或 /工薪 月薪 5000
/排班 月休 4           # 设置月休方案
/打卡 上班             # 上班打卡，下班发 /打卡 下班
```

如果班次是固定的，例如每天 `08:00-20:00`、午休 1 小时不算钱，直接说：

```text
每天 8 点到 20 点，月休 4 天，5、14、18、25 号休息
```

AI 会按这段口头描述重排整月班表；历史打卡也可以一句话批量补：

```text
把 11 月 1 号到 20 号每天 8 点到 20 点补上，5 号和 14 号休息
```

## 指令

### 排班

| 指令 | 说明 |
| --- | --- |
| `/排班 帮助` | 生成图文使用手册（t2i 图片，失败时回退文字版） |
| `/排班 生成 [YYYY-MM]` | 按当前月休方案重排整月（默认本月） |
| `/排班 查看 [YYYY-MM]` | 整月班表 + 工时 + 工资 |
| `/排班 本周` | 本周 7 天 |
| `/排班 模式 4` / `6` / `8` | 切换月休天数，并自动重排 |
| `/排班 时间 09:00 18:00 60` | 设置班次与每班扣休分钟（支持 22:00 06:00 夜班） |
| `/排班 偏好 周末` / `/排班 偏好 均匀` | 休息日是否优先落在周末 |
| `/排班 请假 10月1号到10月21号` | 把这段日期标成未上班 / 请假，不计薪；首次打卡前的日期也会自动显示「未上班」 |
| `/排班 请假 恢复 10月1号到10月21号` | 恢复为正常工作日 |
| `/排班 请假 查看 [YYYY-MM]` | 查看本月已标记的未上班 / 请假 |
| `/排班 图 [YYYY-MM]` | 把月历渲染成约 1080P 图片：右上角天气图标 + 温度（不显示城市）、时段问候；今天黄色高亮、边框按当天进度走灯带，已完成绿色、未上班蓝色（走 AstrBot 的 t2i 服务） |

### 打卡

| 指令 | 说明 |
| --- | --- |
| `/打卡 上班` | 记录当前时间开始计时 |
| `/打卡 下班` | 结束计时并按班次规则扣除饭休 |
| `/打卡 状态` | 现在几点、今天已经上了多久、在不在班、今天班次；进行中会显示本段计时 |
| `/打卡 补 11-20 09:00 18:00` | 补录某天；只补今天可写 `/打卡 补 09:00 18:00` |
| `/打卡 删 11-20` | 删除某天全部打卡 |

### 工时 / 工薪

| 指令 | 说明 |
| --- | --- |
| `/工时 今日`、`/工时 本周`、`/工时 本月 [YYYY-MM]` | 工时汇总 |
| `/工时 明细 [YYYY-MM]` | 每天一行：实记 / 计划 / 加班 |
| `/工薪 时薪 22.5 1.5` | 时薪 + 加班倍率；也可写成 `/工薪 时薪 22.5 2026-10` 只改某个月 |
| `/工薪 月薪 5000` | 月薪制，按全月合同工作日折算时薪；未上班 / 请假不计薪，实际在职天数按比例发 |
| `/工薪 月薪 5000 2026-10` | 只改 2026 年 10 月的工资，11 月保持原来的 3400 / 5000，历史月份互不覆盖 |
| `/工薪 阶段 实习 2026-10` | 把 2026 年 10 月标为实习期；`/工薪 阶段 正式 2026-11` 标正式期，按月分开统计 |
| `/工薪 年收入 [2026]` | 今年的实际收入：只算已经打卡上班的天数，给应发、到手、计薪天数，以及实习 / 正式分栏和逐月明细 |
| `/工薪 加班 1.5` | 单独改加班倍率 |
| `/工薪 加班 1.5 8` | 同时改加班倍率与每日标准工时（8 小时起算加班） |
| `/工薪 本月 [YYYY-MM]` | 工资拆解：正常 + 加班 − 缺勤 − 罚款 − 固定扣款 = 到手 |
| `/工薪 预测` | 按排班干满全月的预计工资（已扣固定款）；和「年收入」不同，这个才会用未来班表 |
| `/工薪 日薪` | 一天多少钱、月薪约多少 |

### 发薪中心与今日考勤

| 指令 | 说明 |
| --- | --- |
| `/今日考勤` | 单独发一张今日考勤图：今天上了多久、时薪多少、按小时累计今天已获得多少钱、距下班多久、本月应得 / 实得 / 未发、上月固定应发 / 已到账 / 未发、未发合计、下次发薪日、还要上多久 |
| `/发薪 查看` | 发薪规则、下一笔、未发合计、每月应发 / 已到账 / 未发明细 |
| `/发薪 月底` | 当月工资当月最后一天发（默认） |
| `/发薪 次月 15` | 压一月，次月 15 号发上月工资；31 号遇到短月自动截到月末 |
| `/发薪 提醒 开` / `/发薪 提醒 关` | 发薪日到点提醒开关（默认开） |
| `/发薪 提醒 17:30` | 改发薪日提醒时间（默认 17:00） |
| `/发薪 到账 2026-10 5000` | 登记 2026 年 10 月工资累计到账 5000；金额可小于应发，表示部分到账 |
| `/发薪 撤销 2026-10` | 撤销该月到账登记 |

发薪日当天有未发工资时，到设定时间会主动发消息：「发工资啦，合计未发 ¥X，到账了吗？」；
回复 `/发薪 到账 YYYY-MM` 即可销账。未到发薪日的当月工资会计入「未发合计 / 未来待发」，
但只有过了发薪日仍未到账的部分才计入「已到发薪日未发」。

要放开得在插件配置里分别勾选「允许 AI 帮用户打卡」「允许 AI 删除某天打卡」，且工具描述要求
「用户本轮明确说要打卡 / 删打卡」才调用。AI 改提醒和文案默认允许，但同样只在用户明确要求时写库。

## 排班规则

- **月休 4 天**：按自然周单休，休息日落在周日（月内 5 个周日时居中取 4 个）。
- **月休 6 天**：取 3 个完整周末（周六 + 周日），等价「三个双休」。
- **月休 8 天**：取 4 个完整周末，即双休。
- 关闭「周末优先」后，休息日按整月均匀间隔铺开，休息总数始终精确等于 4/6/8。
- 生成的班表里，工作日都套用同一个班次（默认 09:00-18:00，扣休 60 分钟 = 8h/天）。

## 工时与工资口径

- **计划工时** = 工作日 × 每班有效工时。
- **实际工时** = 打卡记录合计；打卡时若当天是工作日且时长 ≥ 4 小时，自动扣掉设定的饭休分钟。
- **每日标准工时** 默认 8 小时；工作日每天先按 `min(计划工时, 标准工时)` 算正常工时，超过部分才算加班。12 小时班次会自然拆成 8 小时正常 + 4 小时加班。
- **正常工时** = 每天 `min(实际, 计划, 标准工时)`。
- **加班工时** = 工作日 `max(0, 实际 − min(计划, 标准工时))`；排休日打卡默认整段算加班（可在配置里关）。
- **缺勤** = 首次打卡之后、已经过去的工作日里完全没有打卡的天数；首次打卡之前不算缺勤。
- **应发工资（时薪制）** = 正常工时 × 时薪 + 加班工时 × 时薪 × 加班倍率 − 缺勤扣款。
- **应发工资（月薪制）** = 月薪 + 加班工时 × 折算时薪 × 加班倍率 − 缺勤扣款。折算时薪 = 月薪 ÷ 当月计划工时；缺勤扣款 = 月薪 ÷ 当月排班天数 × 缺勤天数。
- **到手工资** = 应发工资 − 罚款 − 每月固定扣款。固定扣款只在月度汇总/到手工资里扣，不参与日薪结算，避免某天出现负数。
- 月薪制按**实际在职工作日 / 全月合同工作日**折算应发月薪；首次打卡之前的日期自动显示「未上班」，手动标记的未上班 / 请假也不计薪，避免月中入职却拿整月工资。
- **工资按月存**：每个月有自己的工资档案（计薪方式、月薪、时薪、实习 / 正式）。改 11 月工资不会回写 10 月；只有在改「当前月」时才顺便更新默认设置，历史月份已有班表 / 打卡的会先按旧工资自动存档。
- **实际已挣**：单月汇总里的「实际已挣」只按已经出勤的日期累计，进行中的打卡也实时计入；「应发 / 全月预测」才按整月排班推算，两者分开显示。
- **年收入**：只遍历有班表 / 打卡、且不属于未来的月份；月薪制每有一个实际出勤工作日加一天日薪，时薪制按实际工时算正常工资和加班费，未发生的工作日不加钱。年收入同时给出应发和扣掉罚款、固定扣款后的到手，并按实习 / 正式分开汇总。
- **出勤天数**统计所有有打卡的日期；「工作日出勤」单独统计，方便核对排班达成率。年收入里的「计薪天数」只数实际出勤的工作日，休息日加班只加加班费、不再加一天日薪。
- 标记未上班 / 请假的日期会保留原班次时长，用于折算日薪和时薪；恢复后回到正常工作日。
- **缺勤扣款**默认关闭，只统计天数不扣钱，避免漏打卡导致工资变负数；需要严格核算时在插件配置里打开。
- 打卡记录跨天（22:00 上班、次日 06:00 下班）会自动按 24 小时进位计算。

## 上下班提醒规则

- 只看**当天在班表里是「工作日」**的人；休息日、请假没班次的一律不推。
- 上班提醒在 `班次开始 − 提前分钟` 触发，下班提醒在 `班次结束 − 提前分钟` 触发。
- 每条提醒按「人 + 日期 + 类型」落一条 `reminders` 记录，同一天不会重复轰炸；
  服务重启、错过后 5 分钟内仍会补发一次。
- 当天已经打过上班卡就不发上班提醒；已经打完整段下班卡就不发下班提醒。
- 下班的打卡还挂着（上班卡在计时）时，提醒里会点名「你 09:00 的上班卡还在计时」。
- 夜班（如 22:00-06:00）的下班提醒会在次日班次结束时触发。
- 提醒发到该员工**最近一次说话的会话**（群聊或私聊）；从没发过指令的人没有会话记录，自然收不到。
- 文案是温柔版：上班按开始时间说「早安 / 晚上好」，会写「不用赶，先吃点东西，路上慢一点」，并提示到了发 `/打卡 上班`；下班写「快收工啦」和还剩几分钟，并承诺打完卡马上算账。
- **休息日提醒**是独立开关：只在前一天排班是「工作日」、后一天是「休息日」时，于下班时间结束后提醒一次；如果周六/周日排班写着上班，就不会误报休息。
- 休息日提醒内容会数连续休息：双休说「明天、后天都休息，连休两天」，单休说「明天休息，今晚放心收工」，连休 3 天以上说「明天起连休 N 天」。可在 WebUI 提醒区或 `/提醒 休息 开|关` 控制。

### 加班提醒

- 只对工作日、且上班卡还在计时的人检查；实际工时达到「每日标准工时」（默认 8 小时）时推一条加班提醒。
- 提醒里写：今天已经工作多久、超过标准多少、当前加班倍率、已产生加班时长、比平时多约多少钱、加班时薪。
- 每人每天只推一次；按「人 + 日期 + 加班」落 `reminders` 记录，不会和上下班提醒互相顶掉。
- 员工可以自己发 `/提醒 加班 关` 关掉；插件配置里也有全局「超时加班提醒」总开关。
- 标准工时与倍率可发 `/提醒 加班 9`、`/工薪 加班 1.8 9` 修改，AI 也能在聊天里改。

### 每月固定扣款

- 扣款是「工资之外的固定费用」，和罚款分开记：房租、社保、公积金、水电、餐费、通勤、话费都可以自定义标签。
- 两种周期：`每月` 从起始月开始一直扣；`仅本月` 只扣指定月份。
- 同一员工、同一标签、同周期再次添加时，会更新原金额，不会重复堆行。
- 汇总会显示：扣款逐项、扣款合计、扣款前工资、到手工资；全月预测也同步扣除固定款。
- 日薪/某天入账只算当天工资，不摊固定扣款；固定扣款统一在月度到手工资里扣。
- AI 加扣款必须由用户明确说出标签和金额，例如「每月房租 1500」「这个月水电 120」；可在配置里关闭「允许 AI 管理每月扣款」。

### 自定义提醒文案

每个人可以单独改上班 / 下班两段文案，在聊天里发：

```text
/提醒 自定义 上班 早安 {nickname}，今天 {start}-{end}，路上慢一点
/提醒 自定义 下班 快收工啦 {nickname}，还有 {before} 分钟，记得打卡
/提醒 自定义 查看
/提醒 自定义 清空
```

WebUI 右侧「提醒设置」也有两个多行输入框，保存后立即生效。

可用占位符（发送时自动替换）：

| 占位符 | 替换成 |
| --- | --- |
| `{nickname}` | 员工昵称 |
| `{date}` / `{day}` | `11月21日` |
| `{start}` / `{end}` | 班次开始 / 结束时间 |
| `{minutes}` / `{hours}` | 本班有效工时，如 `8小时` |
| `{before}` | 提前分钟数 |
| `{type}` | `上班` / `下班` |
| `{greeting}` | `🌤 早安` / `🌙 晚上好` / `🌇 快收工啦` |
| `{punch}` | 打卡提示句（下班时会区分「还在计时」和「还没完整打卡」） |
| `{tomorrow}` | 接下来的休息日预告：明天单休、明天+后天双休、连休 N 天 |
| `{weather}` | AI 查到的天气行；模板里不写也会自动补在最后 |

留空 = 使用默认温柔版；文案最多 500 字，渲染后最多 800 字。

### AI 联网天气提醒

1. 先在 AstrBot WebUI 的「设置 → 联网搜索」里**开启联网搜索**，并选好搜索服务（Tavily / 博查 / Brave / Firecrawl / 百度 / Exa / AnySearch / SerpAPI / DeepSeek 任一，填好对应密钥）。
2. 用户发 `/提醒 城市 宜宾`（或 WebUI 填「天气城市」），插件会记住城市并打开天气开关。
3. 上班/下班提醒触发时，插件调用 AstrBot 内置的联网搜索工具查该城市当天天气，再把搜索结果交给当前对话模型写成一句 20~50 字的提醒，例如 `🌦 宜宾 · 多云转小雨 18~24℃，出门带把伞`。
4. 同一个人、同一天、同一时段的结果缓存 30 分钟（可配），避免每条提醒都重复搜索。
5. 没有开启联网搜索、没有搜索密钥、搜索失败或超时（20 秒搜索 / 30 秒生成）时，**静默不显示天气**，提醒本身照常发送，不会因为天气失败而丢提醒。

天气依赖 AstrBot 的联网搜索能力，不是插件自己直连气象接口；所以「搜索服务是否可用」决定天气能不能出现。

## 下班入账结算

- 发 `/打卡 下班`（或在聊天里让 AI 打下班卡）时，回执会直接算：**今天入账 ¥X**、本月累计实发 ¥Y、全月预计 ¥Z。
- 时薪制：今天正常工时 × 时薪 + 加班工时 × 时薪 × 加班倍率。
- 月薪制：当天有实记工时，按「月薪 ÷ 当月排班天数」记一天日薪，再加加班费。
- 还没设工资时，不显示金额，改为提示发 `/工薪 时薪 18` 或 `/工薪 月薪 5000`，并回退展示本月实际 / 计划工时。
- 结算放在打卡回执里，不额外单独推送，避免和下班提醒重复轰炸。

## 界面外观（液态玻璃 + 自定义背景）

- 卡片统一是磨砂玻璃：26px backdrop blur + 170% 饱和度 + 顶部折射高光 + 细密噪点，叠在彩色光斑上会有液态玻璃的通透感。
- 右侧「背景与玻璃」卡片提供 5 套预设氛围（极光夜 / 樱雾晨 / 深空蓝 / 暖霞 / 青柠汽水），也可以上传自己的壁纸。
- 上传的图片先在浏览器里压成最宽 1600 像素的 JPEG 再入库，不会把原图几百 MB 塞进去；建议用横版动漫壁纸。
- 「背景模糊」0–30px、「压暗程度」0–85% 两个滑杆实时生效，松手自动保存；「恢复默认」回到原来的纯色渐变。
- 外观设置存在 `settings` 表，跟具体员工无关，换浏览器打开还是同一套背景。
- 浅色主题下压暗层会换成白色蒙版，保证深色文字依旧清晰。
- 点日历某一天会打开当天抽屉：可以补录上下班、删除单条打卡、清空当天；抽屉层已修正点击穿透问题，输入框和按钮都能正常操作。
- 日历下方/右侧新增「费用构成」玻璃卡片：左边是 SVG 环形占比图，中间显示本月扣款总额，右边按自定义标签列金额与百分比。
- 扣款金额改动会自动保存；下方可直接填「标签 + 金额 + 每月/仅本月」添加，点 × 删除；10 色色板自动分配，标签多了也不会混色。
- 英雄卡金额改为「本月到手」，并显示固定扣款 chip；设置区新增「每日标准工时」「超时加班提醒」两个控件。

## 口头排班、工资与罚款

- 直接跟机器人说「这个月月休 4 天，5、14、18、25 号休息，其他都上班」，AI 会把休息日写进当月班表，其余日期全部算上班，不再走自动排休。
- 说「每天上 12 小时，早上 8 点到晚上 8 点」，AI 会改班次时间并重排整月；只说了「每天 12 小时」没给下班时间时，会按上班时间 +12 小时（再补饭休）推算。
- 白班 / 夜班不用自己标：下班时间晚于上班时间就是白班，早于（或等于）上班时间就是跨天夜班，提醒和工时都按跨天处理。
- 说「这个月被罚了 200，迟到」，AI 会记一笔罚款并从当月实发工资里扣；可以记多笔，`/排班 罚款` 看明细，`/排班 罚款 清除` 清空本月。
- 说「每月房租 1500，伙食 900，水电 180」，AI 会按标签逐笔记固定扣款，并算进到手工资；说「这个月话费 59」则只扣本月。
- 说「每天标准 8 小时，超过算 1.5 倍加班」，AI 会更新标准工时、加班倍率；说「加班提醒打开/关掉」也会同步员工开关。
- 说「我月薪 5000」或「时薪 18」，AI 会写工资口径并切到对应计薪方式；月薪会自动按当月计划工时折算时薪，用于加班和缺勤计算。数字没听清时只追问，不会乱填。
- 说「把 11 月 1 号到 20 号都补成 8 点到 20 点，5 号、14 号休息」，AI 会一次补齐这段日期的历史打卡：自动跳过指定休息日、已有相同打卡、未来日期，最多 62 天，补完告诉你补了几天、这个月出勤变成几天。
- 对应 AI 工具：`shift_set_plan`（改休息日/班次）、`shift_add_fine`（记罚款）、`shift_set_pay`（改月薪/时薪）、`shift_bulk_punch`（批量补打卡）、`shift_add_deduction`（加固定扣款）、`shift_set_overtime`（改标准工时/倍率/提醒），都只在用户明确说明时才写库，可在插件配置里分别关掉。
- 不想让 AI 改也可以用指令：`/排班 休息 5,14,18,25`、`/排班 休息 自动`、`/排班 时间 08:00 20:00 60`、`/排班 罚款 200 迟到`、`/工薪 时薪 18`、`/工薪 月薪 5000`、`/扣款 添加 房租 1500 每月`、`/提醒 加班 9`。

## 数据导入导出（WebUI 后台）

右侧 aside 新增「数据导入导出」卡片，三个按钮都在后台页面上：

- **导出备份**：把十张表原样打包成 `shift_board_backup_2026-11-21.json` 下载，用来换机器、重装前留底。
- **导入备份**：选一个之前导出的 JSON 恢复数据。默认是「合并」——同一个人、同月班表、设置会被备份里的值覆盖，打卡和罚款只补不重复；勾选「覆盖导入」会先清空现有全部数据（会弹窗二次确认）。扣款按「人 + 标签 + 金额 + 月份 + 周期」去重。
- **导入打卡 CSV**：给已有考勤表的人一次性搬历史打卡，先选左上角的员工再导。

CSV 格式（第一行表头可留可删，逗号 / Tab / 分号都能识别）：

```csv
日期,上班,下班,备注
2026-11-05,09:00,18:00,补卡
11-06,9点,21:30,夜班
```

- 日期支持 `2026-11-05`、`2026/11/05`、`11-05`、`11月5日`、`20261105`，也支持 Excel 里直接复制出来的 5 位日期序列号。
- 时间支持 `9:00`、`09:00`、`08:00:00`（Excel 常带秒）、`9点`、`9点30`、`0930`，甚至 Excel 的 `0.375` 这种小数；跨天夜班写 `22:00,06:00` 就行，工时按跨天算。
- 表头可以带姓名列，只要包含「日期 / 上班 / 下班」就能自动对列；上下班挤在一格写 `8:00-20:00` 也能拆开。
- 工作日班次会自动扣饭休（4 小时以下短班不扣），同一人同一天同上下班时间的记录会跳过，最多一次导入 2000 行。
- 导入完页面会自动刷新；如果打卡落在别的月份，会自动切到那个月并告诉你，不再出现「明明导进去了却显示出勤 0 天」的错觉。
- 卡片下方会显示「新增 / 重复跳过 / 无法识别」各多少条，认不出的行会贴出前三条原文。

## 数据位置

```text
data/plugin_data/astrbot_plugin_shift_board/shift_board.db
```

SQLite 十张表：`profiles`（每人设置 + 会话 + 提醒偏好 + 标准工时 + 默认工资阶段 + 发薪规则）、`schedules`（每人每月班表）、
`punches`（每人打卡）、`reminders`（提醒去重记录）、`month_rests`（手工指定的休息日）、
`fines`（每月罚款明细）、`deductions`（每月固定扣款，自定义标签）、`settings`（WebUI 外观等全局设置）、
`salary_records`（每人每月的工资档案：计薪方式、月薪、时薪、实习 / 正式）、
`salary_payouts`（每人每月的到账登记：金额、到账日期、备注）。
备份这个文件就等于备份所有人的排班、工时、工资和提醒状态。

多人使用时是「同库分表行」：`user_key` 形如 `aiocqhttp:12345678`（平台 + 账号 ID），
所有查询都带 `user_key` 条件，A 的打卡、工资、提醒不会出现在 B 的记录里；
WebUI 里切换员工只是切换看谁的记录，不会互相影响。

- 休息日提醒与上下班提醒分开记录、分开发送；员工级 `rest_reminder_enabled` 控制休息日提醒，全局配置 `remind_enabled` 仍控制整个提醒任务是否启动。
