# 排班工坊 · 工时与工薪（astrbot_plugin_shift_board）

给 AstrBot 用的排班 + 工时 + 工薪插件：月休 **4 / 6 / 8 天**随时切换，班表按人独立生成，
配合上下班打卡统计实际工时，再按时薪算出正常工资、加班费和缺勤扣款。
附带一个 WebUI 页面（排班日历 + 工时看板），玻璃质感、暗色/亮色都适配。

## 功能一览

| 模块 | 能做什么 |
| --- | --- |
| 排班 | 按月休 4/6/8 天生成整月班表；月休 4 天按周日单休、月休 6 天按三个双休周末、月休 8 天按双休；也可关闭「周末优先」按均匀间隔排休 |
| 打卡 | `/打卡 上班`、`/打卡 下班` 实时计时；`/打卡 补 11-20 09:00 18:00` 补录；`/打卡 删 11-20` 清空当天；也可以让 AI 一次补一段日期的历史打卡 |
| 工时 | 今日 / 本周 / 本月 / 本月明细，统计实际工时、计划工时、加班工时、出勤天数、缺勤天数、完成率 |
| 工薪 | 时薪制或月薪制；月薪自动折算时薪，输出正常工资 + 加班费 − 缺勤扣款 − 罚款、实发合计、全月预测、日薪 |
| 提醒 | 工作日自动推温柔版「早安 / 快收工啦」，提前分钟数可配；已打卡的不重复催，下班打卡顺手结算今天入账 |
| AI 工具 | 机器人 AI 可直接查班表、今日状态、工时、工资，口头写排班、月薪/时薪、罚款；打卡默认需用户自己发指令 |
| 隔离 | 每个「平台 + 账号」一条独立记录，排班/打卡/工资/提醒全部按 `user_key` 分区，换群不串数据 |
| WebUI | `排班日历`：点任意日期可补录或删除打卡；`工时看板`：实发工资、完成率环、近 14 天工时柱状图；顶部可切员工、切月休方案、翻月；右侧可导出/导入整库备份、导入打卡 CSV |

## 安装

1. 把整个 `astrbot_plugin_shift_board` 目录放进：

   ```text
   <AstrBot 根目录>/data/plugins/astrbot_plugin_shift_board
   ```

2. 打开 AstrBot WebUI → 插件管理 → 找到「排班工坊 · 工时与工薪」→ 启用 / 重载插件。
3. 在 QQ 里发送 `/排班 帮助` 查看全部指令。
4. WebUI 里点插件卡片，进入「排班日历 · 工时看板」页面即可打开看板（右侧还有提醒设置）。
5. 如果想让别的人也用：把目录或 zip 发给他们，各自装在自己的 AstrBot 里即可。
   每套部署用一个独立的 `shift_board.db`，彼此的排班、打卡、工资完全分开。

> 依赖：只用 AstrBot 自带的 `aiosqlite`，无需额外 pip 安装。

### AI 可以直接调用

插件注册了 9 个 LLM 函数工具，机器人在 AI 对话里可以自己调用（需要模型支持 function calling）：

| 工具 | 作用 |
| --- | --- |
| `shift_get_schedule` | 查某月班表：工作日/休息日、班次、工时与工资概览 |
| `shift_get_today` | 今天上不上班、班次、是否正在计时、今日工时 |
| `shift_get_hours` | 今日 / 本周 / 本月工时、出勤、缺勤、完成率 |
| `shift_get_pay` | 某月工资拆解与全月预测（月薪/时薪都支持） |
| `shift_punch` | 帮用户打卡（默认关闭，见配置 `允许 AI 帮用户打卡`） |
| `shift_set_plan` | 口头排班：月休、指定休息日、班次、每天几小时 |
| `shift_add_fine` | 口头记罚款，从当月实发里扣 |
| `shift_set_pay` | 口头设置月薪 / 时薪 / 加班倍率（默认开启，见 `允许 AI 设置月薪 / 时薪`） |
| `shift_bulk_punch` | 批量补一段日期的打卡，如「11月1号到20号每天8点到20点，5号14号休息」 |

写操作收得很紧：AI 打卡默认被拦，只能由用户自己发 `/打卡` 指令；要放开得在插件配置里
勾选「允许 AI 帮用户打卡」，且工具描述要求「用户本轮明确说要打卡」才调用。

## 排班规则

- **月休 4 天**：按自然周单休，休息日落在周日（月内 5 个周日时居中取 4 个）。
- **月休 6 天**：取 3 个完整周末（周六 + 周日），等价「三个双休」。
- **月休 8 天**：取 4 个完整周末，即双休。
- 关闭「周末优先」后，休息日按整月均匀间隔铺开，休息总数始终精确等于 4/6/8。
- 生成的班表里，工作日都套用同一个班次（默认 09:00-18:00，扣休 60 分钟 = 8h/天）。

## 工时与工资口径

- **计划工时** = 工作日 × 每班有效工时。
- **实际工时** = 打卡记录合计；打卡时若当天是工作日且时长 ≥ 4 小时，自动扣掉设定的饭休分钟。
- **正常工时** = 每天 `min(实际, 计划)`。
- **加班工时** = 每天 `max(0, 实际 − 计划)`；排休日打卡默认整段算加班（可在配置里关）。
- **缺勤** = 首次打卡之后、已经过去的工作日里完全没有打卡的天数；首次打卡之前不算缺勤。
- **实发工资（时薪制）** = 正常工时 × 时薪 + 加班工时 × 时薪 × 加班倍率 − 缺勤扣款。
- **实发工资（月薪制）** = 月薪 + 加班工时 × 折算时薪 × 加班倍率 − 缺勤扣款。折算时薪 = 月薪 ÷ 当月计划工时；缺勤扣款 = 月薪 ÷ 当月排班天数 × 缺勤天数。
- 月薪制下「月薪基数」固定，只按缺勤和加班调整；未设置月薪时自动回落到时薪制。
- **出勤天数**统计所有有打卡的日期；「工作日出勤」单独统计，方便核对排班达成率。
- **缺勤扣款**默认关闭，只统计天数不扣钱，避免漏打卡导致工资变负数；需要严格核算时在插件配置里打开。
- 打卡记录跨天（22:00 上班、次日 06:00 下班）会自动按 24 小时进位计算。

## 上下班提醒规则

- 只看**当天在班表里是「工作日」**的人；休息日、请假没班次的一律不推。
- 上班提醒在 `班次开始 − 提前分钟` 触发，下班提醒在 `班次结束 − 提前分钟` 触发。
- 每条提醒按「人 + 日期 + 类型」落一条 `reminders` 记录，同一天不会重复轰炸；
  服务重启、错过后 5 分钟内仍会补发一次。
- 当天已经打过上班卡就不发上班提醒；已经打完整段下班卡就不发下班提醒。
- 下班的打卡还挂着（上班卡在计时）时，提醒里会点名「你 09:00 的上班卡还在计时」。
- 夜班（如 22:00-06:00）的下班提醒会在次日班次结束时触发。
- 提醒发到该员工**最近一次说话的会话**（群聊或私聊）；从没发过指令的人没有会话记录，自然收不到。
- 文案是温柔版：上班按开始时间说「早安 / 晚上好」，会写「不用赶，先吃点东西，路上慢一点」，并提示到了发 `/打卡 上班`；下班写「快收工啦」和还剩几分钟，并承诺打完卡马上算账。

## 下班入账结算

- 发 `/打卡 下班`（或在聊天里让 AI 打下班卡）时，回执会直接算：**今天入账 ¥X**、本月累计实发 ¥Y、全月预计 ¥Z。
- 时薪制：今天正常工时 × 时薪 + 加班工时 × 时薪 × 加班倍率。
- 月薪制：当天有实记工时，按「月薪 ÷ 当月排班天数」记一天日薪，再加加班费。
- 还没设工资时，不显示金额，改为提示发 `/工薪 时薪 18` 或 `/工薪 月薪 5000`，并回退展示本月实际 / 计划工时。
- 结算放在打卡回执里，不额外单独推送，避免和下班提醒重复轰炸。

## 界面外观（液态玻璃 + 自定义背景）

- 卡片统一是磨砂玻璃：26px backdrop blur + 170% 饱和度 + 顶部折射高光 + 细密噪点，叠在彩色光斑上会有液态玻璃的通透感。
- 右侧「背景与玻璃」卡片提供 5 套预设氛围（极光夜 / 樱雾晨 / 深空蓝 / 暖霞 / 青柠汽水），也可以上传自己的壁纸。
- 上传的图片先在浏览器里压成最宽 1600 像素的 JPEG 再入库，不会把原图几百 MB 塞进去；建议用横版动漫壁纸。
- 「背景模糊」0–30px、「压暗程度」0–85% 两个滑杆实时生效，松手自动保存；「恢复默认」回到原来的纯色渐变。
- 外观设置存在 `settings` 表，跟具体员工无关，换浏览器打开还是同一套背景。
- 浅色主题下压暗层会换成白色蒙版，保证深色文字依旧清晰。
- 点日历某一天会打开当天抽屉：可以补录上下班、删除单条打卡、清空当天；抽屉层已修正点击穿透问题，输入框和按钮都能正常操作。

## 口头排班、工资与罚款

- 直接跟机器人说「这个月月休 4 天，5、14、18、25 号休息，其他都上班」，AI 会把休息日写进当月班表，其余日期全部算上班，不再走自动排休。
- 说「每天上 12 小时，早上 8 点到晚上 8 点」，AI 会改班次时间并重排整月；只说了「每天 12 小时」没给下班时间时，会按上班时间 +12 小时（再补饭休）推算。
- 白班 / 夜班不用自己标：下班时间晚于上班时间就是白班，早于（或等于）上班时间就是跨天夜班，提醒和工时都按跨天处理。
- 说「这个月被罚了 200，迟到」，AI 会记一笔罚款并从当月实发工资里扣；可以记多笔，`/排班 罚款` 看明细，`/排班 罚款 清除` 清空本月。
- 说「我月薪 5000」或「时薪 18」，AI 会写工资口径并切到对应计薪方式；月薪会自动按当月计划工时折算时薪，用于加班和缺勤计算。数字没听清时只追问，不会乱填。
- 说「把 11 月 1 号到 20 号都补成 8 点到 20 点，5 号、14 号休息」，AI 会一次补齐这段日期的历史打卡：自动跳过指定休息日、已有相同打卡、未来日期，最多 62 天，补完告诉你补了几天、这个月出勤变成几天。
- 对应四个 AI 工具：`shift_set_plan`（改休息日/班次）、`shift_add_fine`（记罚款）、`shift_set_pay`（改月薪/时薪）、`shift_bulk_punch`（批量补打卡），都只在用户明确说明时才写库，可在插件配置里分别关掉。
- 不想让 AI 改也可以用指令：`/排班 休息 5,14,18,25`、`/排班 休息 自动`、`/排班 时间 08:00 20:00 60`、`/排班 罚款 200 迟到`、`/工薪 时薪 18`、`/工薪 月薪 5000`。

## 数据导入导出（WebUI 后台）

右侧 aside 新增「数据导入导出」卡片，三个按钮都在后台页面上：

- **导出备份**：把七张表原样打包成 `shift_board_backup_2026-11-21.json` 下载，用来换机器、重装前留底。
- **导入备份**：选一个之前导出的 JSON 恢复数据。默认是「合并」——同一个人、同月班表、设置会被备份里的值覆盖，打卡和罚款只补不重复；勾选「覆盖导入」会先清空现有全部数据（会弹窗二次确认）。
- **导入打卡 CSV**：给已有考勤表的人一次性搬历史打卡，先选左上角的员工再导。

CSV 格式（第一行表头可留可删，逗号 / Tab / 分号都能识别）：

```csv
日期,上班,下班,备注
2026-11-05,09:00,18:00,补卡
11-06,9点,21:30,夜班
```

- 日期支持 `2026-11-05`、`2026/11/05`、`11-05`、`11月5日`、`20261105`，也支持 Excel 里直接复制出来的 5 位日期序列号。
- 时间支持 `9:00`、`09:00`、`08:00:00`（Excel 常带秒）、`9点`、`9点30`、`0930`，甚至 Excel 的 `0.375` 这种小数；跨天夜班写 `22:00,06:00` 就行，工时按跨天算。
- 表头可以带姓名列，只要包含「日期 / 上班 / 下班」就能自动对列；上下班挤在一格写 `8:00-20:00` 也能拆开。
- 工作日班次会自动扣饭休（4 小时以下短班不扣），同一人同一天同上下班时间的记录会跳过，最多一次导入 2000 行。
- 导入完页面会自动刷新；如果打卡落在别的月份，会自动切到那个月并告诉你，不再出现「明明导进去了却显示出勤 0 天」的错觉。
- 卡片下方会显示「新增 / 重复跳过 / 无法识别」各多少条，认不出的行会贴出前三条原文。

## 数据位置

```text
data/plugin_data/astrbot_plugin_shift_board/shift_board.db
```

SQLite 七张表：`profiles`（每人设置 + 会话 + 提醒偏好）、`schedules`（每人每月班表）、
`punches`（每人打卡）、`reminders`（提醒去重记录）、`month_rests`（手工指定的休息日）、
`fines`（每月罚款明细）、`settings`（WebUI 外观等全局设置）。
备份这个文件就等于备份所有人的排班、工时、工资和提醒状态。

多人使用时是「同库分表行」：`user_key` 形如 `aiocqhttp:12345678`（平台 + 账号 ID），
所有查询都带 `user_key` 条件，A 的打卡、工资、提醒不会出现在 B 的记录里；
WebUI 里切换员工只是切换看谁的记录，不会互相影响。

```text
├─ planner.py           # 排班算法、工时汇总、工资计算（纯函数，可单测）
├─ store.py             # SQLite 存储，按 user_key 隔离 + 老库自动补列
├─ render.py            # 聊天文本、提醒文案与 t2i 月历模板
├─ _conf_schema.json    # 插件配置 Schema
├─ metadata.yaml        # 插件元数据
├─ pages/shift-board/   # WebUI 排班日历 + 工时看板 + 提醒设置 + 背景外观
│  ├─ index.html
│  ├─ style.css
│  └─ app.js
├─ .astrbot-plugin/i18n/
│  └─ zh-CN.json            # WebUI 页面标题等中文本地化
├─ tests/
│  ├─ test_planner.py       # 算法自测（20 个用例，含指定休息日 / 白夜班 / 罚款）
│  ├─ test_reminder.py      # 提醒 / AI 工具（含口头排班、罚款）/ 多人隔离自测
│  └─ smoke_check.py        # 装到 AstrBot 后的导入 / 存储 / 渲染 / 路由冒烟自检
```

## 自测

```bash
# 算法单测（纯标准库，任意 Python 3.10+ 都能跑）
python tests/test_planner.py

# 提醒 / AI 工具 / 隔离自测 + 冒烟自检（用 AstrBot 的 venv，在 AstrBot 根目录下执行）
venv\Scripts\python.exe ..\..\data\plugins\astrbot_plugin_shift_board\tests\test_reminder.py
venv\Scripts\python.exe ..\..\data\plugins\astrbot_plugin_shift_board\tests\smoke_check.py
```
